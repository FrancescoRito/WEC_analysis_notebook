
# WEC Data Analysis 🏁

This project features data analysis of the **FIA World Endurance Championship (WEC)** using two Python notebooks based on official CSV datasets. The goal is to explore performance, consistency, strategy, and race dynamics in both **free practice** and **race** sessions.

## 📘 Repository Contents

### `WEC_Analysis_freepractice.ipynb`
Detailed analysis of **free practice** sessions:

- Calculation of average pace and consistency
- Comparative visualizations and distributions

### `WEC_Analysis_race.ipynb`
Analysis of the **race** (to be added/completed):

- Pace evolution throughout race stints
- Team comparisons and strategic insights

## 📁 Data Structure

The data is sourced from the official [fiawec.alkamelsystems.com](http://fiawec.alkamelsystems.com/index.php/) website and provided in **CSV format**. Please place the CSV files inside the `data/` folder of the project.

> ⚠️ The data files are **not included** in the repository due to licensing restrictions from the official source.

## ⚙️ Requirements

Install the required Python libraries with:

```bash
pip install pandas matplotlib seaborn numpy jupyter

```
Additional libraries (e.g., `plotly`, `scikit-learn`) may be used and are listed at the beginning of the notebooks if needed.

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/your-username/wec-analysis.git
cd wec-analysis
```

2. Place your CSV data files in the `data/` directory

3. Launch Jupyter Notebook:

```bash
jupyter notebook
```

4. Open and explore the `.ipynb` files
